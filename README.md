# Minecraft Advanced Client Module

**Smooth Tracking & Adaptive Auto Aim System for Minecraft 1.20 – 1.21**

High-performance client-side module focused on precise tracking, smooth motion, and clean modular architecture. Built for players who want stable and configurable assistance without heavy overhead.

---

### Features

- Adaptive smooth tracking system  
- Configurable response curves  
- Low CPU / GPU impact  
- Modular design (easy to extend)  
- Full support for Forge & Fabric  
- Clean open structure

### Configuration

All settings are stored in `config/default.json`.  
You can adjust:

- Tracking speed  
- Smoothness multiplier  
- FOV limits  
- Target priority
